# References

This file lists the sources behind the facts in this course: QBE and its intermediate language,
the Zig language and standard library that pebc is written in, the papers behind the parsing,
testing and optimization techniques the chapters use, and the history of B, C and the compilers
the "History" and "In the wild" sections tell about. Use it to check a claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the
Internet Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or
changes). For source code on GitHub, the archived link points to
[Software Heritage](https://archive.softwareheritage.org/), an archive of public source code.
Zig documentation links point at the Zig 0.17.1 documentation and QBE links at QBE 1.2, the
versions the course targets. Program output, line counts and timings shown in the chapters come
from running the course's own code and aren't listed here.
